# Delta Safe Guide

**Промышленное программирование ПЛК Delta: от физики контактов до безопасного кода**

Этот репозиторий — методическое пособие по программированию контроллеров Delta с фокусом на **безопасность, надёжность и промышленную культуру**.  
В основе — реальный код вентустановки, который мы шаг за шагом превращаем из «рабочего, но кривого» в идеальный промышленный пример.

## 🎯 Цель проекта
Создать практическое руководство, которое:
- объясняет **физику процессов** до написания кода;
- учит проектировать **fail‑safe системы**;
- показывает **реальные ошибки и их исправление** на живом коде;
- даёт готовые **шаблоны и чек‑листы** для промышленной эксплуатации.

## 📚 Структура методички
- **Часть 0: Переключение мышления** — чем автоматизация отличается от IT.
- **Часть 1: Физический мир** — НО/НЗ, схемы подключения, безопасные цепи.
- **Часть 2: Синтаксис безопасности** — команды LD, таймеры, счётчики.
- **Часть 3: Организация кода** — режимы, состояния, подпрограммы.
- **Часть 4: Аварии и защита** — диагностика, приоритеты, аварийные остановы.
- **Часть 5: Продвинутые темы** — ПИД, Modbus, связь с HMI.
- **Приложения** — таблицы настроек, диагностика, шаблоны.
